# InAmigos Foundation Awareness Webpage

## Overview

This project is a responsive NGO awareness webpage developed using HTML, CSS, and JavaScript to showcase the mission, initiatives, projects, and social impact of InAmigos Foundation.

The webpage was created as part of an internship assignment focused on spreading awareness about the foundation's work and presenting information in a visually engaging and accessible format.

---

## Features

* Responsive and modern user interface
* Hero section with awareness banner
* About InAmigos Foundation section
* Mission and Vision section
* Showcase of flagship projects
* Social impact statistics
* Image gallery highlighting initiatives
* Areas of focus and project highlights
* Contact information section
* Social media integration
* Smooth scrolling navigation
* Interactive hover effects and animations

---

## Projects Highlighted

### Project SEVA

Community welfare initiatives, humanitarian support, and social outreach activities.

### Project BACHPANSHALA

Educational support and learning opportunities for underprivileged children.

### Project UDAAN

### Project JEEV
